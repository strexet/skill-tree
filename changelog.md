# Changelog

## 0.6.0 (2026-11-20)

### Added

- Game Design, Mechanics and Balance are independently callable operations. Design records and Director handoffs retain the selected sources, decisions and review evidence.
- Five focused 3D operations cover references, Blender, texturing, motion and Unity alongside the 3D coordinator. The guides describe staged acceptance, the creature catalog and review evidence for animation contact and held blends.
- Full Cycle delivers an explicitly selected task or group from intake through implementation and a reviewed PR merged into `develop`.

### Changed

- Implement Next commits accepted task changes. Implement All commits each accepted task and locally integrates the reviewed snapshot. Work Through Next leaves a reviewed branch for an explicitly requested merge.
- Director documentation covers design, narrative and production handoffs, source-impact inspection and selected branch reports. Feature folder guidance describes how the responsible area owns code and local documentation.

### Fixed

- Future writers report missing referenced files, active state and expected history before replacing task metadata. Owned refresh can restore a missing generated AGENTS instruction block.

## 0.5.0 (2026-11-16)

### Added

- The Director flavor coordinates registered project folders and repositories from Codex. Nine Director operations cover planning, child dispatch, owner decisions, evidence review, run diagnostics and controlled installation.
- Narrative workflows support story drafts, continuity and gameplay review, author-approved canon snapshots and source-backed handoffs into Director plans.
- Tasks support topics and intake batches. Grouped selection and guarded migration preserve task identities and queue history.
- Built-in direct replacement and network polling policies apply by default. Reviewed API contract locks pin a baseline and verify affected contracts before PR readiness.

### Changed

- Completed dependencies require matching current validation and reviewed source coverage before dependent work proceeds.
- New run events carry UTC recording times, and Core replay accepts legacy events. Director Audit reports missing event sequences, unresolved checks and repeated failures.

## 0.4.0 (2026-11-09)

### Added

- `skill-tree-plugins` manages project-scoped external skills from the catalog, URLs and local sources. Configuration previews show the exact installation, update, binding or removal before confirmation.
- Workflows support ordered plugin bindings before, during and after operations. Repeated occurrences retain independent parameters and instructions. Optional integrations cover a Ponytail review pass and post-Processing editorial and interview passes.
- `skill-tree-clarify-tasks` supports resumable interviews, guarded revisions and current confirmation for individual tasks and groups. Auto delegates bounded decisions to agents and records the rationale. Manual sends decision questions to the owner.
- Owned profiles expose the built-in `static-inspection` recipe. Explicit declarations take precedence.

### Changed

- The installer defaults to core skills and offers optional plugin setup in interactive sessions. The catalog groups candidates by workflow integration point and records the evidence and prerequisites for each candidate.
- Local delivery binds the reviewed source and target refs to a verified merge receipt. PR merge consent names the target, and changes to the review scope require current evidence. Legacy consent without a recorded target requires fresh owner authorization.

### Fixed

- Plugin imports resolve Markdown reference links and balanced paths and ignore apparent links inside fenced examples and HTML comments.
- Core refresh and rollback preserve binary plugin resources. Relocation preserves the retained package generation, and plugin transactions protect unrelated staging and backup files.
- Interrupted stale validation attempts can be reconciled after verifying that the original bound local process group has ended. Earlier checks and task history remain available.
