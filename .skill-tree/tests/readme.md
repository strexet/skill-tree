# Behavioral Verification

Run `npm run test:py` and `npm run test:node`. Tests use temporary repositories/installations. Source generation, document rules and portable package resources receive strict validation. No live provider installation or Unity execution occurs.

PR cycle fixtures exercise direct-owner merge parsing, negative/conflicting instructions, persistent findings, exact head/base review, CI and approval gates, provider pagination/access loss, idempotent PR/comment operations and conditional merge arguments. Workspace fixtures exercise local Git remotes, multiple claimed runs, canonical queue routing, recovery, semantic event replay, portable execution locators and environment/resource prerequisites. Installed general/web/unity packages execute independently and pass profile refresh/verification; the installed controller fixture provisions and re-admits the exact worktree. No fixture publishes a public PR, performs a live merge or launches a paid/product runtime.

Selected Implement All fixtures verify exact-ID admission, priority/tie order, shared dependency closure, atomic rejection of invalid or blocked groups, unrelated-task exclusion and frozen scope across resume. Standalone CLI fixtures exercise `snapshot_ids` in installed general/web/unity packages against temporary Git repositories.

Completed-dependency fixtures verify consumer handoffs, accepted current contracts, complete source coverage, pending attempts, changed source/recipe/artifacts and immutable outcomes across registered worktrees. Original-source integration and execution stops remain covered.
