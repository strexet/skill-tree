# Input System Fixture

The admitted profile includes Input System 1.11. Use the installed InputTestFixture for controlled device/command events, explicitly registered layouts and preserved fixture setup/teardown. Use deterministic commands or bounded frame checks according to the assertion. Simulated touch cannot establish physical-device behavior. The [Input System test contract](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.11/manual/Testing.html) defines fixture scope.
