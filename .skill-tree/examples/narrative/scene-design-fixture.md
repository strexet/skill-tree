# Scene Design Fixture

The synthetic work uses `work-harbor-evacuation`, `continuity-harbor` and illustrative source revision `draft-scene-inspection-v1`. Fixture names identify the example and confer no canon status.

## Playable inspection

| Card item | Example |
| --- | --- |
| Identity | `scene-dock-inspection` depicts an inspection after `event-floodgate-warning`. The warning occurs at tide hour three. |
| Presentation | The inspection follows the arrival beat. The relay log is optional before the inspection. |
| Function | The player secures a path to the dock and learns which evidence changes captain trust. |
| Participants | The apprentice needs a route and fears losing time. The captain can issue access and fears an unverified alarm. The captain knows only the public tide warning. |
| Entry | The apprentice can ask for access. A marked receipt is available only after a relay log visit. |
| Exit | Direct access with captain trust after showing the receipt, or supervised access without new trust. |

`beat-request` opens the inspection. The captain refuses direct access without proof. At `beat-offer-route`, the player can show a receipt when possessed or request supervision. The choice uses a distinct visible action. At `beat-record-access`, the captain grants the corresponding access. The next dock scene reads the access type and trust state. A skipped log leaves the receipt choice unavailable.

## Quiet watch and flashback

`scene-harbor-watch` follows the evacuation. The player observes a lantern or walks onward. The watch establishes relief between pressured episodes and has no route gate. A flashback may show the warning at tide hour three. The editorial placement of the flashback can move earlier without altering the warning's event time.
