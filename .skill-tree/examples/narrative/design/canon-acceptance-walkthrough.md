# Synthetic Canon Acceptance Walkthrough

The example uses a temporary work and synthetic decisions to illustrate mechanics. No receipt in the example represents a real author. The original base contains a relay scene and a quest that depends on the scene.

1. Prepare both revised records together. The proposed scene refers to the quest and the proposed quest still refers to the scene. The candidate can contain both revisions as long as the selected composition closes the normative graph.
2. Inspect the full candidate and any unchanged normative dependent. A reviewer finding about an unsupported time cue remains an in-scope blocker until the time and route evidence agree. Keep a separate untested audio cue outside the review scope. If a work definition or Ink source contributes evidence, bind the exact file hashes and select the reviewed packet.
3. Present the compatible pair, an alternative retaining the older cue and the exact digest. Describe the effect on the selected work and the unaffected work pinned to the older snapshot. A request to explore the alternative authorizes draft work within scope.
4. In the decline example, the author declines the revised pair. No accepted snapshot is created. The candidate drafts and the earlier snapshot remain available.
5. In the acceptance example, the owner explicitly accepts the exact digest and matching packet where applicable. Verify the new selected pin and the old pin. Compare the earlier generic cue with the later quest-specific cue. Retcon or retirement would require a separately reviewed and explicitly approved scope.

The synthetic helper check verifies grouped record acceptance and old snapshot preservation. The walkthrough does not assert a live independent reviewer, audience observation or production approval.
