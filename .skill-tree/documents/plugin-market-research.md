# External Skill Market Research

## Scope and evidence ownership

The research date is 2026-11-05. The [durable market map](../history/research/plugin-market-map.json) owns 38 candidate entry records across 11 candidate repository families, 19 repository revision/maintenance snapshots, 25 supporting source records, eight primary adoption pages and seven outcome/evaluation-method records. Candidate records bind exact source URLs, repository revisions, available entry blob identities, dependencies, license evidence and explicit host/flavor statuses.

Actual pinned entry texts and targeted tool, dependency, activation and failure requirements form the inspection scope. Large entries receive interface-focused inspection. Complete package security audits, resource closure, candidate invocation, installation, model benchmarks and product/runtime execution remain unperformed. Source acquisition establishes package facts rather than target-workflow quality.

The [workflow decisions](plugin-workflow-decisions.md) prioritize demonstrated task/review quality, explicit time/cost reporting and honest limitations. Recommended candidates and bundles are empty at every integration point across general, web and unity flavors. The [system research](plugin-system-research.md) owns repository execution seams; [agent compatibility](agent-compatibility.md#external-plugin-qualification) distinguishes core installation support from external invocation qualification.

## Evidence levels

| Evidence | Supported assertion | Excluded inference |
| --- | --- | --- |
| Distribution declaration | A producer, directory or installer names a package/host. | Successful target discovery, invocation or effectiveness. |
| Pinned source inspection | The selected entry contains recorded instructions and requirements. | Complete standalone closure, safe execution or task improvement. |
| Upstream outcome report | A publication describes a bounded experiment. | Reproduction by Skill Tree or transfer across adapter, host or task. |
| Target-workflow comparison | A separately admitted paired run observes activation and independent acceptance. | Universal skill/model ranking or unrelated domain qualification. |
| Product/runtime qualification | Matching browser, Editor, player, device or service evidence supports the exact assertion. | Runtime proof from source review, helper tests or process availability. |

Every candidate lacks a target-workflow observation. Upstream host claims remain declarations. Topic fit and installation paths provide no verified flavor/hook behavior. Unsupported status refers to the inspected entry and current generic adapter, rather than every upstream host.
