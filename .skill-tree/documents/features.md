# Current Features

All four flavors expose the 22 shared operations below. The director flavor adds nine operations for cross-project coordination.

| Operation | Current responsibility |
| --- | --- |
| `skill-tree-add-pending-task` | Capture understood intent with identity, semantic classification and numeric priority. |
| `skill-tree-process-future-pending` | Research selected Pending work and record scoped dispositions and dependencies. |
| `skill-tree-clarify-tasks` | Refine exact tasks through researched question rounds, guarded revisions and current acceptance by the owner in Manual or a delegated agent in Auto. |
| `skill-tree-implement-next-future-task` | Implement an exact or highest-priority eligible Prioritized task with acceptance evidence. |
| `skill-tree-work-through-next` | Orchestrate one root and required dependencies through a retained checkpoint. |
| `skill-tree-implement-all` | Orchestrate the initial Prioritized snapshot or an explicit selected group. |
| `skill-tree-full-cycle` | Deliver an explicitly selected task or group from Pending through implementation and one reviewed PR merged into `develop`. |
| `skill-tree-repo-documentation` | Initialize or repair source-backed current documents, task metadata and navigation. |
| `skill-tree-repo-documentation-audit` | Inspect implementation, repair document drift and persist findings and coverage. |
| `skill-tree-create-documents-snapshot` | Create an explicit bounded documentation archive. |
| `skill-tree-pr-review-cycle` | Record PR review/fix progress and gate explicitly authorized publication and merge. |
| `skill-tree-plugins` | Inspect installed and known sources, preview exact package changes and configure ordered binding occurrences. |
| `skill-tree-narative` | Develop narrative drafts, review continuity and gameplay, and record explicitly accepted canon snapshots. |
| `skill-tree-game-design` | Develop and review the game design and GDD for an explicitly scoped project. |
| `skill-tree-game-design-mechanics` | Develop mechanic rules, examples, boundaries and checks. |
| `skill-tree-game-design-balance` | Establish balance assumptions, models, checks and playtest evidence. |
| `skill-tree-3d` | Coordinate Unity asset creation, staged review and scoped delivery. |
| `skill-tree-3d-references` | Prepare source references and a reviewable reference package. |
| `skill-tree-3d-blender` | Produce and review Blender model and surface outputs. |
| `skill-tree-3d-texture` | Produce and review texture outputs against the selected model. |
| `skill-tree-3d-motion` | Produce and review motion, including continuous multi-camera playback evidence. |
| `skill-tree-3d-unity` | Integrate the selected asset into Unity and verify the target scene and applicable motion checks. |

The [3D guide](skill-tree-3d-guide.md) documents stage inputs, checks and delivery. The [Director workflow](director-workflow.md) covers the Director-only operations `setup`, `intake`, `plan`, `run`, `decide`, `status`, `review`, `audit` and `install`, each with the `skill-tree-director-` prefix.

General packages use discovered repository recipes. Web packages add browser and hosted-evidence boundaries. Unity packages add Editor, package, fixture and runtime isolation contracts. Concrete specialization follows resolved capabilities.

Copy installation, owned refresh/verification, interrupted-transaction recovery, one retained rollback generation and optional provider bridges are implemented. Global specialization, symlink installation and automatic migration are unsupported. Provider discovery configuration supplies no native-runtime qualification.

Direct-owner merge guards, manager option validation, explicit verified rebind, source-recipe composition and generated snapshot exclusions are implemented. The [quality audit](skill-quality-audit.md) records matching regressions and bounded agent observations. [Future work](future.md) owns deferred improvement scope.
