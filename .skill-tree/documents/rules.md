# Repository Rules

[AGENTS.md](../../AGENTS.md) owns repository instructions. [Maintainer contract](skill-repository-creation-instructions.md) owns source editing, generation and release boundaries. [Document rules](../common/references/document-rules.md) own English declarative prose and filename conventions.

Matching installed operations under `.agents/skills/` govern repository development. Source edits belong in canonical templates, common resources, domain resources or owning implementation modules. Generated representative packages and installed snapshots receive no independent edits.

Explicit developer authorization determines implementation, continuation, commit and external-operation scope. An installed profile, queue entry, historical checkpoint or audit recommendation grants no independent authorization. Audit findings remain Backlog until explicit selection and the required intake/research workflow.

The [task workflow](../common/references/future-workflow.md), [validation policy](../common/references/validation-policy.md) and [run workspace contract](../common/references/run-workspaces.md) own selection, evidence and isolation requirements. [Security](security.md) owns metadata and secret boundaries.
