# Agent Compatibility

`.skill-tree/config/providers.json` owns provider IDs, detection, destinations, optional bridges and official discovery references. Provider-required directories retain exact spelling. The source release changes no provider support claim; matrix entries describe discovery configuration rather than native runtime qualification for every release.

Local project-scoped copy installation supports matrix destinations. Soft providers require explicit selection. Generic installation uses the explicit target root without a native-discovery claim. Global, symlink and upstream passthrough specialization are unsupported; the installer never silently forwards uncomposed source templates. Temporary installation/bridge fixtures establish local filesystem behavior only.

Eight independent Codex scenario observations cover English/Russian intake, clarification, standalone processing, selected-group continuation, paused status inspection, merge examples, unrelated requests and snapshots. The [observation record](../history/validation/next-version/agent-conformance-live.json) binds actual agent identities, inherited model configuration, request/package fingerprints, artifact assertions and semantic review. The host does not expose an exact inherited model ID. Native discovery across every provider, live publication and universal model adherence remain unqualified.
