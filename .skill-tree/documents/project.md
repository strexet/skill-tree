# Skill Tree Project

Skill Tree provides ten repository workflows for documentation, snapshots, task intake, research, implementation, orchestration and PR review. Developers install a general, web or unity flavor into an explicitly selected project.

The source release version is 0.3.0. [Features](features.md) records operation boundaries. [Installation architecture](installation-architecture.md) owns composition and installation behavior. [Repository rules](rules.md) identify editing and authorization contracts.

The source repository uses the installed general packages under `.agents/skills/`. The installed packages form a reviewed execution snapshot. Canonical templates, common resources and domain resources own future source changes.

Local fixture qualification covers deterministic helpers and filesystem behavior. Eight independent Codex observations qualify bounded workflow scenarios with recorded context and explicit host limitations. Native provider discovery, live publication, domain runtimes and universal model adherence require separate evidence. [Quality audit](skill-quality-audit.md) records the current repair and qualification scope.
