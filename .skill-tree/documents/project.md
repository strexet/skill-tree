# Skill Tree Project

Skill Tree provides twelve core operations for repository documentation, snapshots, task intake, research, clarification, implementation, orchestration, PR review, plugin management and narrative development. Developers install the general, web, unity or director flavor into an explicitly selected project. The director flavor adds nine operations for cross-project coordination.

The source release version is 0.5.0. [Features](features.md) records operation boundaries. [Installation architecture](installation-architecture.md) owns composition and installation behavior. [Repository rules](rules.md) identify editing and authorization contracts.

The source repository uses the installed general packages under `.agents/skills/`. The installed packages form a reviewed execution snapshot. Canonical templates, common resources and domain resources own future source changes.

Local fixture qualification covers deterministic helpers and filesystem behavior. Eight independent Codex observations qualify bounded workflow scenarios with recorded context and explicit host limitations. Native provider discovery, live publication, domain runtimes and universal model adherence require separate evidence. [Quality audit](skill-quality-audit.md) records the current repair and qualification scope.
