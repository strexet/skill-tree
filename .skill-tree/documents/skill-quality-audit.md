## Actual agent observations

The [observation record](../history/validation/next-version/agent-conformance-live.json) contains actual agent identities, provider, inherited model configuration, request and installed-package fingerprints, objective assertions and semantic review. Agents receive realistic requests and isolated fixtures without proposed answers or audit conclusions. No evaluation contacts GitHub or another remote provider.

`scripts/agent-conformance.py` prepares unused temporary projects outside existing Git repositories, grades concrete task/checkpoint/source/archive artifacts and validates complete unique report coverage. Grader unit tests reject missing, duplicated, failed, unreviewed and unidentified evidence. Unit fixtures establish grader behavior and supply no actual-model claim.

The host does not expose an exact inherited model identifier. Qualification covers the observed Codex configuration and recorded package contexts. Universal model adherence, other host configurations and native provider discovery remain unqualified.

## Instruction assessment

Installed entrypoints contain approximately 154–315 whitespace-delimited words before conditional reference loading. Complete package Markdown contains approximately 2,306–9,497 words per operation in the initial measured snapshot. The counts establish no actual context, latency or token-cost result. Standalone resources intentionally duplicate shared contracts.

The [Agent Skills specification](https://agentskills.io/specification) and [OpenAI skill guidance](https://learn.chatgpt.com/docs/build-skills) support focused entrypoints and progressive resource loading. Conditional reference routing remains a design opportunity requiring measured behavioral evidence before an efficiency claim.

No Unity Editor, browser product, hosted deployment, physical device or live PR publication occurs. Provider-matrix declarations receive structural validation; current native support across every provider remains separate qualification.

Expected defect reproductions establish useful Red evidence; final regression passes and actual-agent observations remain distinct records. Historical findings and terminal outcomes retain original verdicts and timestamps.
