# Skill-Tree-Unity: Audit Documents

Read rules, manifest, current documents and [output contract](references/documentation-output-contract.md). Inspect relevant source/configuration/tests using [discovery](references/repository-discovery-checklist.md); document-to-document comparison alone is insufficient. Repair drift and missing required documents from current evidence. Capture confirmed issues in Backlog with IDs and evidence. Read [metadata](references/workflow-metadata.md) and [retention](references/history-retention.md); persist an audit with stable finding IDs, source coverage and unrun checks. Refresh manifest; report corrections, unresolved findings and actual validation. No product implementation is implied.

Read [Unity documentation contract](references/repo-init-instructions.md). Read [Unity safety](references/unity-safety.md). Inspect relevant serialized state, pinned versions and lifecycle. Separate static, Editor, Play Mode/UI, player and device evidence; authorization remains scoped.

Generated prose follows [document rules](references/document-rules.md). No unrelated changes, implicit permission or source/sibling dependency.
