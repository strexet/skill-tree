# Narrative Feedback Review

Trace consequential information from source to presented cue and dependent action. For each route record the information required, available sources, presentation beat, relying action and the visible or audible feedback. Record state changes and delivered signals separately.

Compare the main route, a skip and a failed attempt. A cue may disappear on an optional route even when the engine still offers the action. Review claims of protagonist or NPC knowledge with the continuity procedure. Report unreachable information, premature disclosure, weak feedback and hypotheses about interpretation as separate findings.

When a route relies on an absent clue, compare an alternate timely cue with wording that no longer assumes the clue. State whether the proposed verification requires source inspection, runtime playback or an actual human observation.
