# World state between events

Describe a transition only when the target work needs a changed condition. Start with the verified earlier pin and an explicit route and period. Keep the world transition separate from story presentation and from accepted status.

| Field | Record |
| --- | --- |
| Prior state | Exact work, event or snapshot references and the condition before change |
| Trigger and scope | Event, affected actors, elapsed time and route or outcome conditions |
| Causal steps | Actor goal, resources, available knowledge and intermediate actions |
| Later condition | Changed institutions, supplies or relationships, plus visible evidence |
| Authority and uncertainty | Supported facts, proposal status, missing causes and any author decision |

Walk the causal chain from trigger to visible sign. Check whether each actor knew enough and had time, access and resources to act. If a cause is missing, qualify the later condition or ask about the exact gap. Apply any approved change to the intended later work without rewriting an earlier snapshot.
