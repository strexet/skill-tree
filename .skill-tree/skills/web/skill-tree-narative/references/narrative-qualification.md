# Narrative qualification

Use a small positive case and a nearby adverse variant for consequential narrative claims. Record the exact work, accepted snapshot or selected draft, source paths and version, the route, start state and expected finding or outcome. A check may report a narrower observed scope than the authoring request. Keep absent or unverified evidence visible.

| Evidence lane | Qualifies | Requires |
| --- | --- | --- |
| Structural | Valid fields, dependencies, paths, hashes and declared conditions | Exact artifact, deterministic assertion and source identity |
| Semantic | A grounded craft, continuity or knowledge finding | Exact reviewed sources, route and reasoning |
| Standalone runtime | Executed actions, available choices, final state and save behavior | Matching compiled source, tool identity, traces and cleanup |
| Unity integration | Behavior in the selected game and host | Authorized project, exact Editor and build context, fixture and runtime observations |
| Human playthrough | Observed understanding, expectations and pacing | Consented session, exact build and unprompted observations |

One result may support several criteria in the same lane. A reachable clue establishes presentation availability. Player interpretation and observed understanding remain separate. Bind a revision to affected earlier results and rerun the relevant checks when source, route, build or environment changes. Keep the historical run beside the updated result.

Use the companion qualification matrix to select a small case. Report unresolved fixtures, external prerequisites and uncovered routes explicitly.
