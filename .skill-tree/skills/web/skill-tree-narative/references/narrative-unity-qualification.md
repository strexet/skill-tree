# Unity Narrative Qualification

Select an authorized project, clean execution scope, exact editor and package versions, adapter version, test scene or save, matching profile and build identity. Record concrete route IDs, starting state, expected input and resulting state before opening play mode. Preserve any original save or workspace outside the test fixture.

| Evidence class | Expected observation |
| --- | --- |
| Import or compile | The exact story and adapter compile under the pinned editor. |
| Play-mode route | Input selects the intended choice, delivers feedback, and records acknowledged host state. |
| Save and restore | The same build restores the declared checkpoint and one-time effects remain unique. |
| Migration | A named old schema migrates to the supported target or fails explicitly. |
| Human observation | A real participant supplies a scoped expectation or inference with recorded exposure. |

Choose the expected action sequence, signal and source fingerprints for each route. A missing tool, package mismatch, missing fixture or unexpected modal blocks affected controls. Preserve valid earlier receipts, diagnose the prerequisite and record cleanup before a changed retry. A compile result establishes import or compile evidence only.

The standalone Ink harness uses a separate lane. A request to qualify an actual Unity project must identify and authorize the real host scope.
