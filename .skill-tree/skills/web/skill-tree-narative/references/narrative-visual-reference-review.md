# Review visual references and appearance continuity

Record visual provenance separately from the character state and actual design decision. Use a stable reference ID, linked state, source locator, version or digest, origin and usage evidence. For a generated reference, record available generation context without assuming reproducibility or permission.

| Status | Meaning |
| --- | --- |
| Reference | Source material under consideration |
| Proposed design | Selected or adapted features awaiting owner decision |
| Approved design | Specific approved features with decision evidence |
| Production asset | Implemented artifact with revision and validation evidence |

Review selected and excluded features against the exact brief, not visual similarity alone. Compare declared views or poses. Record observed agreement, disagreement and unavailable evidence. A proposed silhouette can be retained while an incidental symbol or identity inference is excluded. Keep unknown usage permission visible and ask before adopting or reusing the material. Design approval and asset provenance remain distinct.
