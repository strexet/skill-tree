# Quest Agency Review

Select the exact work, quest and route before comparing the offered action with the implemented consequence. Record the player verb, prompt, permitted choices, available facts, expected cost and actual resulting action.

1. Check that the offered verb describes what happens. An uncertain cost may be intentional. A misleading action requires separate author intent and evidence.
2. Check that a declined commitment cannot silently become an accepted commitment. Preserve a meaningful refusal when the declared route supplies one.
3. Verify that an optional encounter remains optional for the declared route. Compare the state and information available on both paths.
4. Give a minimal fix and a materially distinct alternative. Record effects on canon, coverage and production effort, then name the route to rerun.

Use one positive route before diagnosing faults. A playable option proves the availability of an action. Player understanding requires separate observation.
