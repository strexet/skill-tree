# Character appearance by state

Start with one selected character state, work, period and authority status. Keep a readable identity cue distinct from a variable costume or injury. Trace each meaningful visual change to role, resource, place, event or an explicit proposal.

| Field | Record |
| --- | --- |
| Identity and state | Character ID, state ID, work, period, authority and causal sources |
| Silhouette and face | Outline, proportions, age cues, posture and recognizable forms |
| Clothing and materials | Palette, wear, job equipment, accessories and reasons |
| Motion and readability | Relevant camera or viewing context, movement cues, hand use and required comparison views |
| Stable and variable features | Traits to preserve, state-specific changes, causes and applicable period |
| Reference decisions | Features to take, reinterpret or reject, with exact provenance and approval status |

Use the project camera and constraints when available. Keep unknown technical budgets explicit. Compare front, three-quarter or gameplay-distance views as appropriate. A state mismatch needs a source-linked correction or a new owner decision. A visually appealing variant cannot establish a new biographical fact.
