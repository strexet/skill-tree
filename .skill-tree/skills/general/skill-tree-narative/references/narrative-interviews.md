# Narrative interviews and creative decisions

Use interviews for decisions with meaningful creative consequences. Resolve a factual question from an accepted source when the scope and evidence allow an answer. Keep uncertainty visible when the source cannot answer.

## Ask and capture

1. Rank up to three questions by consequence. State the affected work, outcome, record or scene and the evidence or constraints already established.
2. Give viable options with distinct effects, tradeoffs and a recommendation. Include a neutral or deferral option when work can proceed without committing the disputed outcome.
3. Record a decision ID, scope, source IDs and fingerprints, considered options, recommendation, actual owner response, owner rationale or an explicit unavailable value, rejected alternatives and any authorized draft action. Distinguish quoted response from agent interpretation.
4. Keep an unanswered recommendation unresolved. Separate permission to explore a draft from approval of reviewed canon. Refer actual snapshot acceptance to the canon approval workflow.

## Resume an interview

Compare the saved scope and fingerprints with the current context record. Preserve an answered fact or owner decision when supporting sources and scope still match. Reopen only the affected decision after a material change. Identify the changed source, unresolved choice and held edit. Continue independent or reversible work within existing authority. A new recommendation requires a new response when the recommendation changes an accepted choice.
