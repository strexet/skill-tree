# Dramaturgy Card Catalog

The catalog separates analytical models, techniques and player effects. The playbook locator identifies the source entry. A method key identifies a reusable approach, while a scene or intention record identifies an authored application. Method records remain outside normative canon dependencies.

## Choose a card

Start with a source-backed observation and the intended player experience. Use the last column to locate a likely method. Read the matched card and any relevant overlap only. For a weak payoff, start with [setup and payoff](narrative-craft-information.md#setup-payoff). For competing accounts, start with [attributed testimony](narrative-craft-testimony.md#rashomon). If a quiet scene already sustains atmosphere or pacing, retaining the scene is a supported conclusion.

Every card names the selection signal, source attribution or playbook locator, game adaptation, intended player experience, misuse risk, concrete example and suitable evidence. Record an observed result separately from an intended effect. An authored clue and an executed clue presentation support different claims from an observed player interpretation.

Setup and payoff supports later understanding or action. Foreshadowing becomes significant in hindsight. Recognition changes the meaning of a known event. A single beat can serve more than one function. Record each function separately before comparing affected routes.

## Example application

A proposed intention `intent-switch-warning` names `setup-payoff` and points from the observation in `scene-relay-log` to a possible choice in `scene-selector`. The authoring record states the purpose and route scope. The accepted scene records establish canonical events and outcomes. Normative dependencies refer to accepted narrative records rather than method keys.

A trace can show whether the warning appears before a choice. A neutral question such as “What did the switch warning change about the options?” can help assess a player's interpretation. Record a testable expectation until player observations support a result.
