# Route mixed intake to drafts and decisions

Open the intake record and identify the selected work and continuity. Group fragments by the underlying event, character, law, location or scene. Compare exact supplied fragments against an existing source before drafting a second record.

| Finding | Route |
| --- | --- |
| Existing identity or event | Link the existing ID and record the new source locator as provenance. |
| Distinct new entity | Propose one candidate with a stable ID and the exact applicable source. |
| Confirmed required source | Record a normative dependency only when the proposed fact requires the source to hold. |
| Mention, visual inspiration or attributed version | Preserve the link as provenance or an attributed claim. |
| Contradictory source or ambiguous scope | Keep both claims and hold only the affected proposal until a consequential decision or compatible reading resolves the conflict. |

Prepare reversible sorting while a conflict remains open. Ask one to three high-impact questions with distinct outcomes and one recommendation. Explain why the recommendation fits the current experience and which work remains possible before the author answers.
