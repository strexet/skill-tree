# Scene Adaptation Across Contexts

Select exact source and target work, continuity, time, admitted routes and accepted pins before comparing the scene. Record explicit draft selections and assumptions. Refer to the source through a stable ID and the reviewed revision or pin. Copying words or moving a file alone supplies no authority to change the world event.

## Classify the operation

| Operation | Identity and scope |
| --- | --- |
| File relocation | Keep the scene ID, event ID and content. Record an updated locator through the supported authoring workflow. |
| Presentation shift | Retain the event and time. A new placement of the same authored scene changes presentation in a draft revision. A distinct depiction has a new scene ID and references the shared event. |
| Event revision | Prepare a draft revision of the event or a new event where identity actually changes. Review changed chronology, causality and authority. |
| Separate variation | Allocate a new ID and keep an attributed `adapted_from` reference to the exact source. Select the new work or continuity explicitly. |

An `adapted_from` reference records provenance. A normative dependency is a separate claim. Keep accepted snapshots reproducible and route material canon changes through current review and owner approval.

## Compare both contexts

Record the function, actor availability and goals, knowledge, prerequisites, setup, payoff, route condition, outcome and production dependencies in each context. Confirm the target contains enough causal and dramatic support to make the scene playable. Recheck what the source loses if the source presentation is moved or cut. Inspect the impact on dialogue, animation, interaction objects, conditions and implementation maps. Capture the affected package and open choices before drafting.

A harbor inspection can move from a first-act encounter to a later recollection without changing the historic inspection date. A new work can depict the same inspection through a witness with a new scene ID. A separate late-night confrontation changes the event and receives explicit variation provenance. If removing the original inspection also removes the only warning about the floodgate latch, the source route needs restored preparation even when the new scene works.
