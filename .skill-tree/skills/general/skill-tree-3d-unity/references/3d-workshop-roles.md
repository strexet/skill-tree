# Workshop Roles

## Art pipeline

Resolve the work and asset identity, expected outputs, owner choices and tool scope using the [shared workflow](3d-workflow.md). Route the smallest applicable role. Keep a short handoff with revision, work state, required checks and limitations. Use Pending intake for authorized independently actionable follow-up work.

## Project setup

Inspect the owned project profile and exact Blender, Editor, package and render pipeline configuration. Distinguish portable workshop source, target-specific outputs and ignored machine bindings. Use an isolated native target with a pinned recipe, one writer for each mutable source or target, and a cleanup policy. Prefer an authorized local route using available tools. Paid services require explicit authority. Report unavailable capabilities before launch. Installation provides procedures and references.

## Asset library curator

Classify candidates by use, adaptation, further search or new creation. Inspect source revision, license, actual inventory, dependencies and compatibility evidence before admission. Keep incoming packages in quarantine until verified. Reuse accepted assets and recipes within the recorded scope. Keep candidate, admitted and rejected states visible.
