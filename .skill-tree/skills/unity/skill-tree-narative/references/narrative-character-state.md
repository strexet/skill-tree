# Character identity, state and work role

Keep one stable character identity across works. Add an applicable state for a period or outcome and a role for each appearance that needs distinct story function. The record convention is additive and preserves existing character cards and snapshots.

| Layer | Contents |
| --- | --- |
| Identity | Stable `identity_id`, durable traits, recognizable ways of acting and established history |
| State | `state_id`, identity, continuity, period, predecessor conditions, causal events, retained traits and changes to goals, obligations, relationships, knowledge or appearance |
| Role | `role_id`, selected `work_id`, applicable state and purpose in the work |
| Appearance | Optional `appearance_id` linked to the state and supported by a separate visual decision when needed |

Resolve the work manifest and predecessor policy first. Select only a state within the declared continuity, period and imported outcomes. Trace every material change to an event, observed evidence or an explicitly unresolved proposal. Identify the later work role without treating the role as a personality change.

A state from an alternate route or later period cannot silently fill an earlier gap. Preserve earlier pins and keep unavailable knowledge explicit. A planned state or visual design does not become accepted through use in a fixture.
