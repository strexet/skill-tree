# Knowledge and Disclosure Traces

Start with the [claim record](narrative-claims.md), scoped work sources and legal routes. Identify the exact claim or supported interpretation under review. Record three independent orders.

| Order | Review question |
| --- | --- |
| World chronology | When did each event occur relative to cause and consequence? |
| Presentation | When is an event, cue or account presented or withheld? |
| Legal route | Which choices and states allow the audience or a participant to reach a beat? |

A flashback or newly read report changes disclosure order and can leave world chronology intact. A route can skip a disclosure while retaining access to the following scene. An ordered event list does not show who learned the facts.

## Record evidence per holder

Use separate holder identities for audience, player character and NPC. Record the claim or inference, route, beat, source record or implementation location and method of acquisition. Distinguish direct observation, testimony, inference and withheld facts. Store an attributed belief with the holder and evidence even when the belief conflicts with the established world facts. The existence of a source does not grant knowledge to every holder.

Distinguish clue presentation from a player choosing a stated interpretation. Both differ from observed understanding, which requires an appropriate participant observation or neutral question. A selected route can include an inferred reading without proving every player formed the inference.

Review a paired route with and without an optional source. For a knowledgeable line, locate an earlier acquisition for the same holder and claim on the same route. If a source is withheld or unavailable, identify the exact holder, beat and missing basis. Offer a route-specific line or an independent later source. Keep action availability, player exposure and author authority separate.

## Ridge example

The relay event establishes a heater short before the first lightning. Ilya initially attributes the problem to the storm. On the inspection route, the player reads the dated log and Ilya observes the relevant entries. On the skip route, the exposed cable and reserve gauge support a choice without revealing the recorded trip time. A synthetic later incident board could provide independent timing evidence after the selector. The current implementation has no incident board. A precise line before an available source remains unsupported even if a proposed later board would disclose the time.
