# Quest Outcomes

Record the trigger, action, immediate feedback, durable effect and next playable entry for each applicable outcome. Preserve deliberate differences when routes converge.

| Outcome family | Authoring question |
| --- | --- |
| Success | What intended goal succeeds, at what cost and with what visible proof? |
| Alternative | Which competing goal can succeed, and which retained state distinguishes the route? |
| Refusal | Where does the player go after declining an offered commitment? |
| Failure | What changes after a player attempts an action and fails? |
| Skip | Which cues, allies and optional benefits are lost, and can required play continue? |
| Re-entry | Which state persists, and which rewards or side effects must not repeat? |

Mark an inapplicable family with a scope reason. A refusal preserves the player's declined intent. Failure records an actual attempt and any resulting cost. Skip bypasses the encounter or optional beat. A shared exit may be correct if the consequences differ or if a deliberate reset has an explicit rationale.

## Review procedure

At a convergence point compare prior allies, knowledge, costs, state and playable access. Identify the intended differences and name each visible or audible signal. A changed variable alone is insufficient evidence for visible feedback. When a prompt promises a tradeoff but both outcomes deliver the same benefit, retain the difference or seek an author decision to clarify the intention. When refusal has no exit, add a reachable next step or change the declared availability of refusal with a recorded author decision.
