# Objects with usable limits

Start with the purpose of the object in the selected work. A meaningful object can establish atmosphere, reveal a fact, alter the state of play or resolve a plot condition.

| Field | Design note |
| --- | --- |
| Identity and origin | Stable ID, provenance, previous owners and relevant condition |
| Appearance and meaning | Visible details, use wear and meaning to specific people or groups |
| Actual capabilities | Possible actions, required resources, output and limits |
| Route availability | Where and when the object appears, who has access and what the user of the object needs to know |
| Setup and consequence | Earlier observation or instruction, later use and player-visible feedback |

For a consequence-bearing object, walk the path from setup through possession or access to the outcome. A late resolution needs a verified capability and a reachable object. Review the skip path separately. When an object serves atmosphere only, retain the local sensory function and omit an artificial state effect.
