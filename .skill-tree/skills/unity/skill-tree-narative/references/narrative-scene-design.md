# Playable Scene and Beat Design

## Establish scope

Use the selected work, continuity, period, route, snapshot and explicitly named draft revisions. A scene may depict or recall a world event. Give the world event identity and time separately from the scene's presentation position. A flashback can move within the work while retaining the event date.

Name the dramatic function in terms of what changes or what useful experience the scene sustains. Possible outcomes include changed situation, knowledge, relationship, expectation, decision or emotional context. Atmosphere, observation and pacing can be useful scene functions without a reversal or irreversible change.

## Draft the scene card

| Field | Required decision |
| --- | --- |
| Scope | Work, continuity, period, scene ID, event reference, selected source revision and admitted routes. |
| Presentation | Trigger, neighboring beats and optional or required placement. |
| Function | Intended audience experience and effect on the next relevant action or interpretation. |
| Participants | Current state, available knowledge, desire, fear, leverage and relevant constraints. |
| Entry | Conditions, information, available actions and unresolved assumptions. |
| Beats | Stable local names for meaningful actions, obstacles, tactics, disclosures, responses and player choices. |
| Exit | Possible outcomes, state changes, audience and actor knowledge, and later dependencies. |
| Evidence | Sources, open questions, proposed review cases and desired player observations. |

Start with a small authored action. Add an obstacle only where resistance serves the scene function. For each consequential decision compare the label, available action and actual result. Separate spoken information, visible evidence and intended subtext. Include a concrete cue for any inference needed later.

Read the entry and exit states together. Identify a changed participant position, available action or expectation where the scene promises change. If the purpose is atmosphere or a pause, describe what the scene sustains and why the placement matters. Keep unresolved author decisions visible. Offer focused options and a recommendation when a material gap cannot be resolved from sources.

## Inspect the playable and quiet cases

In a harbor inspection, the apprentice asks a captain for a key. The captain refuses an unverified request, so the apprentice can show a marked receipt or request a supervised route. The receipt is available only after an optional visit. Both exits preserve a route to the dock but carry different access and trust. A later dock scene reads the selected outcome.

A quiet harbor watch shows residents resting after an evacuation. The scene allows the player to stop or move on. The scene sustains relief and transitions between pressured episodes without requiring a fresh loss. A dated flashback may depict the original flood within the watch scene. Moving the flashback changes disclosure order and leaves the flood date intact.
