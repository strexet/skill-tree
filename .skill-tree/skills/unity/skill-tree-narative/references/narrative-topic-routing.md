# Narrative topic routing

Select the requested output and mutation scope before loading specialized guidance. Bind the work, continuity, period, relevant route and accepted snapshot or deliberate empty baseline. Load the smallest set of topics needed for the request. A broader review lists the selected coverage.

| Request | Initial route | Scope decision |
| --- | --- | --- |
| Critique an accepted scene | Continuity review or narrative design review | Keep the accepted snapshot and project files read-only. Report evidence and suggestions. |
| Add a sequel | Project initialization, then continuation and character evolution as needed | Name the predecessor outcome or ask about incompatible outcomes before drafting dependent changes. |
| Fix an Ink line that exposes unavailable knowledge | Continuity review and Ink handoff | Establish which route and source are authoritative. Treat code or text edits as a separate authorized action when the request only seeks review. |
| Accept a draft as canon | Canon approval | Resolve the exact reviewed package and require the author's actual decision for the package. |
| Unclear whether the request is a proposal or a correction | Context and interview | Ask about the one ambiguity that changes the output. Continue bounded read-only research. |

## Procedure index

| Procedure | Use when | Read first | Expected result |
| --- | --- | --- | --- |
| Project initialization | Establishing an IP or a work | Premise, scope, prior work and constraints | Brief, work definition and first playable target |
| Source intake | Organizing mixed material | Originals, provenance and author guidance | Attributed observations, draft proposals and consequential questions |
| World architect | Designing a playable rule | Intended player action and established world laws | Rule scope, cost, exceptions and observable consequences |
| World consequence audit | Introducing or changing a rule | Previous and candidate rule, affected systems and people | Necessary effects, plausible adaptations and open decisions |
| Setting builder | Creating a place, faction or object | World rule, intended use and relevant participants | A setting record with constraints and actionable affordances |
| Character designer | Creating or revising a person | Work role, pressure and relationships | Causal profile, voice and plausible behavior |
| Character evolution | Developing the same person through change | Stable identity, prior state, events and outcome | Linked later state and work role |
| Scene design | Drafting or revising an episode | Intended function, state, voice and neighboring beats | Scene or dialogue proposal with observable exit |
| Quest design | Designing or revising a playable sequence | Player objective, route constraints and desired consequences | Quest contract with gates, outcomes and feedback |
| Scene adaptation | Transferring a scene or replacing a participant | Both source contexts, role and existing setup | Scoped adaptation proposal and downstream effects |
| Continuity review | Reviewing contradictions, timing or knowledge | Exact accepted and draft records, legal route and relevant evidence | Evidence-based findings and bounded remedies |
| Change impact | Changing a law, scene or relationship | Candidate change, known references and work pins | Normative, optional and suspected affected material |
| Canon library | Finding and organizing records | Selected draft inventory or accepted snapshot | Derived inventory with exact sources and status |
| Canon approval | Accepting a reviewed package | Candidate digest, review evidence and author decision | Accepted snapshot or explicit unresolved prerequisite |
| Narrative gameplay review | Examining agency and feedback | Intended action, actual options and relevant routes | Mismatch findings, trace coverage and playtest questions |
| Visual character brief | Describing a specific character appearance | Identity, period or outcome state and references | A traceable design brief and comparison criteria |
| Legend and culture builder | Developing versions, rituals and everyday practice | Event, attributed viewpoints and place | Cultural records and visible expressions |
| World dynamics | Proposing changes between events | Prior conditions, agents, resources and branch | Plausible branch-scoped state transitions |
| Narrative design review | Improving dramatic function | Authorial objective, selected material and relevant craft methods | Specific observations, options and a way to check effects |
| Ink handoff | Connecting design with executable dialogue | Route contract, authoritative Ink source and state owners | Stable mapping, runtime evidence plan and qualification scope |

A script or helper may establish structure and exact input identity. Narrative review interprets source content. Runtime and human observations require matching evidence. Use the existing Skill Tree operations for queue work within the requested scope.
