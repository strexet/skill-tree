# Story Arc Route Review

Compare an accepted or prior [story arc map](narrative-story-arcs.md) with the exact candidate. Record work, continuity, source revisions and admitted routes before reporting a result. Use stable milestone IDs and inspect the related scene, quest and implementation sources.

## Compare changed structure

For each affected milestone record the old and new event position, cause, presentation or disclosure position, availability and carried outcome. A moved disclosure changes what an audience or actor can know by a beat. A moved world event may change causal prerequisites, available participants and which scenes remain possible.

Select a bounded set of applicable main, optional skip, alternate order and failure routes. Trace required milestones and record the evidence or access that supplies each transition. Inspect the convergence result for losses, relationships and knowledge carried from earlier choices. Report unreachable content, reachable content with a missing cause and a hypothesis about thematic weakening separately.

Recommend a local source, an alternate route or an intentional restructuring. Explain affected sources, route consequences, production cost and needed runtime or player evidence. Keep a scope limitation when the reviewed source lacks a route or observation.

## Compare the harbor variants

| Revision or route | Expected finding |
| --- | --- |
| A flashback reveals the public warning earlier while the tide event remains fixed. | Review earlier knowledge and motivation. The warning date and physical trigger stay fixed. |
| The warning event moves past the boarding decision. | The boarding prerequisite may be impossible on the old timeline. The change affects world chronology. |
| A failed maintenance inquiry costs the spare rope before convergence. | The common dock scene can continue while a rope-dependent option remains unavailable. |
| The common dock scene restores the rope without a source. | The route stays reachable but erases a stated cost. Record a carried-state contradiction. |

An optional witness can add motives without supplying the only actionable deadline. A route may remain reachable after a witness cut while losing thematic depth. Mark that conclusion as editorial and ask for a player observation if comprehension or experience matters.
