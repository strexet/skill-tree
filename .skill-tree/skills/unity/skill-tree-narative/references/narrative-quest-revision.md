# Existing Quest Revision

Pin the current work, accepted revision or selected draft, referenced scenes, current quest function and implementation version. Record a source-backed finding before changing a quest. Classify the finding as agency defect, continuity problem, production constraint or editorial opportunity.

1. Name affected beat, action and outcome IDs and record current behavior.
2. State the function and player control to preserve. Compare the smallest useful change and a materially different alternative by route, cost, consequence and downstream effect. A no-edit outcome is valid if the concern is unsupported.
3. Compare current and proposed behavior in a short table with affected and unaffected routes. Record remaining uncertainty and reruns.
4. Keep the proposal and author choice separate. Rerun affected evidence when the quest, work pin or implementation changes.

For an optional clue that became a required gate, compare adding an alternate cue on the main path with intentionally making the original clue mandatory. The recommendation depends on why the encounter was optional. Preserve the crisis and the player's useful control in either proposal.
