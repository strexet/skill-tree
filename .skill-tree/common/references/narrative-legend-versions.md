# Attributed legend versions

Use a shared event or a single explicitly unresolved incident as the reference point. A retelling has an audience and social function. A retelling can preserve memory, defend an institution, entertain, warn or dispute an account.

1. Pin the continuity, period and place. Record established event facts and deliberate unknowns separately.
2. Give each version a named speaker or group, audience, period, territory, accessible evidence and social purpose.
3. Separate an attributed claim from author truth. A discrepancy becomes an error only when the applicable established sources cannot coexist.
4. Decide what each route exposes and which claims remain unconfirmed. Distinguish a missing attribution from deliberate uncertainty.
5. Preserve unresolved interpretations. Request an author choice only when the design requires an answer for a consequential later decision.
