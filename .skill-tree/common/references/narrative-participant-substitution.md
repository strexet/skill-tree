# Participant Substitution Review

Use [scene adaptation scope](narrative-scene-adaptation.md) and the original dramatic function to prepare a before-and-after role map. Stable character identity does not make every state of the character available on every route.

## Build the role map

For the original and candidate participants, record the exact character and state revisions, work and event time, admitted routes, physical presence, relationship, goal, current obligation, knowledge source, leverage, costs and action capabilities. State the dramatic action the original participant performs. Distinguish canon constraints from an editable tactic or expression.

Replace the action only after checking the candidate can perform the same function. A candidate may use a different tactic, reveal another source, introduce a route-specific substitute or change the scene result. Preserve voice through a short rewritten exchange. Compare every changed line, object, animation, trigger and downstream fact with the original and target route. Keep material author decisions visible.

## Harbor substitution

| Dimension | Original captain | Candidate warden |
| --- | --- | --- |
| Objective | Protect the dock from an unverified alarm. | Keep the evacuation route controlled. |
| Knowledge | Verified warning from the public bulletin. | Public bulletin plus a signed replacement permit. |
| Availability | Present at the dock before the departure order. | Present only on the licensed patrol route. |
| Authority and cost | Can issue a temporary key and accepts risk to the crew. | Can escort a resident but cannot grant an unrestricted key. |
| Voice and action | “Name the berth.” The captain tests the request. | “Stay inside the red marks. I will take the first watch.” The warden offers supervision. |

The warden can preserve the function of providing a route with lower access. Update the available action, escorted state, later trust condition and any escort animation. A draft where the warden reveals the private relay timestamp fails without an evidence source. A route that skips the patrol cannot use the warden. Retain the captain or prepare a route-specific alternative before acceptance.
