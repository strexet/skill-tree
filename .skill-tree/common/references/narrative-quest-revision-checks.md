# Quest Revision Checks

Use a comparison sheet keyed by baseline and candidate fingerprints. For every changed condition, disclosure, actor or effect, record the stable quest, scene or outcome ID, the old and new observation, the named trace and the required evidence. Preserve unaffected source and coverage independently.

Check both offered wording and actual player verb when a passive transition changes into a choice. Evidence carries forward only for the exact inspected inputs and relevant check scope. If an implementation source changes without a corresponding prose change, mark the affected result stale and rerun the named trace. Keep unavailable observations explicit and record the exact condition for reopening an accepted review.
