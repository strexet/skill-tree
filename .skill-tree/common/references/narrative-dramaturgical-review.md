# Actionable Dramaturgical Review

Read the work intent, exact scene, nearby beats, selected canon and admitted player actions. Collect a source-backed observation before choosing a method. Inspect where pressure changes, how a cost becomes visible, which value drives action and whether dialogue or setting already supplies the needed information.

## Make a recommendation

1. State the intended function and a concrete observation tied to a beat, source or route.
2. Classify the finding as a confirmed continuity or behavior blocker, an editorial hypothesis, an intentionally quiet or ambiguous effect, or an unresolved question.
3. Use the [dramaturgy catalog](narrative-craft-catalog.md) to select the smallest relevant set of methods. Explain the fit in plain language.
4. Compare two or three real options if change is justified. Include impact on agency, canon, route availability, nearby beats and production. Retain the current scene when the evidence supports the function.
5. Recommend one bounded edit and a proportionate check. Record author choice and the reason for a rejected alternative when the author decides.

Observed clue presentation supports route coverage. Report inferred motivation or likely emotional effect as a hypothesis unless audience evidence supports the claim. Independent review and actual author authority remain separate from editorial recommendations.

## Worked example

An inspection exchange repeats the rules before the player chooses a dock route. The captain needs credible evidence. The receipt route and supervised route already offer different access. The focused change turns the rule recital into a request for evidence and a supervised offer. A larger change exposes the access rule through an inspectable gate register. The larger change adds implementation and knowledge-state costs. Recommend the text-only edit when the intended result is clearer pressure without a new interaction.

A quiet watch after evacuation provides relief and preserves an intentional pause. The current scene can remain intact. A draft that gives the captain an exact relay timestamp after skipping the source has a separate continuity blocker regardless of the reviewer's view of atmosphere.
