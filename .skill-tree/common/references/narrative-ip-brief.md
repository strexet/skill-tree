# Playable IP brief

Use the brief to initialize a setting or test a broad premise before drafting detailed canon. Start with the desired player experience and a repeatable action. Select a bounded episode with one meaningful choice.

## Build the brief

1. Extract genre, audience intent, signature player verbs, production limits and author constraints. Record what each supplied reference contributes and which details stay excluded. Label invented details as proposals.
2. Write one sentence linking the unusual world condition, the player role and the main tension. Choose three to five pillars that help reject or refine later ideas.
3. Give each pillar a player-visible expression. Use an action, environmental signal, social response or observable consequence. Park background material without a role in the episode.
4. Outline one location, two or three relevant participants, an opening state, a choice and immediate feedback. State the playable boundary and any desired longer-term consequence separately.
5. Separate confirmed author direction, reversible suggestions and unresolved decisions. Ask only material questions. When two requirements conflict, present distinct viable alternatives and explain what each alternative changes.

## Reusable brief

| Entry | Record |
| --- | --- |
| Premise and experience | World condition, player role, audience intent and main tension |
| Pillars | Three to five principles with one visible expression per pillar |
| Constraints and references | Genre, scope, production limits, author boundaries and intended reference use |
| Small episode | Location, participants, opening state, decision, outcome feedback and stopping point |
| Decisions | Author facts, agent suggestions, exact open choices and proposals held by each choice |

When an author requires both an irreversible choice about the same outcome and a fixed outcome, keep the conflict visible. Possible designs include a fixed outcome with an independently consequential cost, or an outcome determined by the player choice. Keep reversible scene preparation separate from the choice.
