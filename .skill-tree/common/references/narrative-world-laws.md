# Playable world laws

Use a law card when a world rule affects available actions, state or consequence. Keep a rule concise enough to test through a playable situation.

| Field | Record |
| --- | --- |
| Identity and source | Stable law ID, approved revision or proposal, rule type and source |
| Scope | Continuity, time, place, actors and conditions that activate the rule |
| Access | Available tools, resources, required knowledge and relevant authority |
| Cost and limits | Consumed resources, output limits and conditions for failure |
| Observability | What participants, the player and the interface can see or infer |
| Exceptions | Accepted exceptions with authority and conditions, plus separate candidate exceptions |
| Play case | An attempted action, observable feedback and expected change in world or character state |

## Review the type of rule

- A physical constraint defines a possible result. An attempt outside the constraint produces an explicit failure or a separately approved exception.
- An enforceable norm defines permitted behavior, monitors and consequences. The same physical action may still succeed when the norm is violated.
- A value or preference shapes choices. Ask how pressure or a changed goal could alter a response. Keep values distinct from physical limits and institutional enforcement.

Review one normal action and one boundary action. Trace each outcome to a stated clause and distinguish author knowledge from evidence available on the route. If an exception needs an undecided resource, cost or authority, retain a proposal and an exact question.
